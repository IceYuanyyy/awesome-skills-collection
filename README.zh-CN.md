## 仓库定位

很多有价值的 Skills 分散在 GitHub、社区帖子、个人笔记、聊天记录甚至截图里，不方便后续统一检索和复用。这个仓库的目标就是把这些资源整理成一个可长期积累的 Skills 收藏库。

核心目标：

- 收藏高质量 AI Skills 与可复用提示词资源
- 保留开源来源信息，方便追溯与更新
- 建立一个适合个人沉淀，也适合公开分享的资源仓库

## 使用方式

### 1. 浏览资源

优先查看 [`collections/`](./collections/) 目录下各个项目的 `README.md`、`SKILL.md` 和配套文件。

### 2. 本地复用

根据你使用的 Agent 或工具链，把真正可安装的 skill 目录复制到本地 skills 目录中。很多 Codex 风格技能都是围绕 `SKILL.md` 组织的。

### 3. 维护来源记录

可以通过 [`collections/SOURCES.md`](./collections/SOURCES.md) 统一记录每个资源的来源、用途和备注，方便后续持续扩充。

### 4. 扩展收藏

后续新增资源时建议遵循同一规则：

- 统一放在 `collections/`
- 保留原始来源信息
- 上游 README 有价值时一并保留
- 值得重点展示的资源再补充到主 README 中

## 收录原则

- 优先收录结构清晰、可复用性强、实用性高的 Skills
- 收藏开源资源时尽量保留原始署名与说明
- 不把临时草稿直接混入正式收藏区
- 把这个仓库当作长期维护的知识资产，而不是临时堆放目录

## 资源渠道

后续可以重点从这些渠道继续扩展：

- GitHub 上以 `SKILL.md`、Prompt、Agent Workflow 为核心的开源仓库
- Codex、Claude Code 等相关社区中的工作流分享
- 开发者博客、经验帖、讨论串里整理得较完整的技能包
- 已经过筛整理、适合复用的个人笔记和项目沉淀
