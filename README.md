## Why This Repository

Useful skills are often scattered across GitHub repositories, personal blogs, communities, screenshots, or chat logs. This repository is designed as a clean hub to preserve valuable skills, track their origins, and make them easier to browse, compare, and reuse.

It is built around three simple goals:

- Collect proven AI skills and reusable prompt assets
- Preserve source attribution for open-source materials
- Build a long-term personal skills library that is also easy to share

## How To Use

### 1. Browse the collection

Start with the folders under [`collections/`](./collections/) and inspect each resource's `README.md`, `SKILL.md`, and supporting files.

### 2. Reuse a skill locally

Depending on your agent or toolchain, copy the actual skill folder into your local skills directory. For example, many Codex-style skills are centered on a `SKILL.md` file.

### 3. Track source attribution

Use [`collections/SOURCES.md`](./collections/SOURCES.md) to keep a simple record of where each collected resource came from.

### 4. Expand the library

When adding a new skill or prompt pack, keep the structure consistent:

- Add it under `collections/`
- Record the original source
- Keep the upstream README if useful
- Document notable use cases in the main README when the item is worth surfacing

## Curation Rules

- Prefer skills with clear structure, reusable instructions, and practical workflows
- Keep attribution intact when collecting open-source resources
- Avoid mixing temporary notes into the curated collection
- Treat this repository as a durable library, not a random dump folder

## Resource Channels

Recommended places to discover more high-quality skills and reusable prompt assets:

- GitHub repositories focused on `SKILL.md`, agent workflows, or prompt engineering
- Open-source communities around Codex, Claude Code, and other agentic coding tools
- Developer blogs or discussion threads that publish complete workflow packs
- Personal notes that have been cleaned up into reusable, documented instructions
